## Explorar
Leer README.md, AGENTS.md, docs/ y prompts/explorar.md.
La IA puede comparar opciones; no debe decidir por el integrante ni empezar una tarea sin que este la elija.

## Implementar una elección
1. Clonar https://github.com/pixeltabletop/jajanken-lupa y actualizar main con git pull --ff-only.
2. Revisar issues y PR abiertos para evitar duplicar trabajo.
3. Registrar una elección voluntaria con ID del backlog y alcance; sin asignar a terceros.
4. Crear rama feature/tema, fix/tema o docs/tema.
5. Acordar primero los cambios que afecten stack, interfaces o datos compartidos.
6. Verificar cambios, revisar git diff y confirmar ausencia de secretos.
7. Commit, push y PR con resultados reales y pendientes.
8. Revisión por otro integrante antes de integrar; no force-push.
