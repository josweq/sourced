# Una guía común para cualquier integrante
No hay prompts que asignen roles. Los archivos con nombres personales se conservan como accesos neutrales.

1. Carga README.md, AGENTS.md y docs/.
2. Usa [explorar.md](explorar.md) para evaluar qué podrías aportar.
3. Después de elegir una tarea, usa [implementar.md](implementar.md).
4. Para revisar trabajo existente, usa [revisar.md](revisar.md).

Nunca compartir credenciales. Notion permanece pausado.
